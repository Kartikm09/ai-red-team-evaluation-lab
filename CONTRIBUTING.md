# Contributing

Contributions should keep the project safe, synthetic, and recruiter-friendly.

## Guidelines

- Use synthetic prompts and outputs only.
- Do not add operational misuse instructions.
- Do not include confidential data or private client names.
- Add reviewer evidence for each new sample.
- Keep scripts standard-library only unless there is a strong reason.

## Suggested Contribution Types

- New safe test cases
- Additional rubric dimensions
- Cleaner report templates
- More multilingual examples
- Script improvements
