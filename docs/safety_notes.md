# Safety Notes

This repository is built for defensive AI safety evaluation.

## Included

- Synthetic prompts
- Synthetic model outputs
- Safe cybersecurity education examples
- Refusal quality examples
- Hallucination and format-following examples
- Multilingual safety consistency checks

## Excluded

- Operational jailbreak instructions
- Steps for bypassing safety systems
- Malware, evasion, credential theft, or exploitation details
- Confidential client data
- Private client names
- Real user personal data

## Reviewer Principle

The goal is to evaluate and improve model safety, not to provide instructions that enable misuse.
